## Что исправлено

| Наблюдение пользователя | Причина в коде | Изменение |
| --- | --- | --- |
| CSV предлагал почти весь каталог, BMP ограничивался Guard | Для `undetermined` разрешалась ручная попытка, для распознанного содержимого применялись native-ограничения | Ручной выбор и «Выбрать всё» используют только `verifiedFileIds`; неизвестное направление недоступно до подтверждения |
| Долго проверялись пары CSV | Windows UNO ожидал строку вместо `(typeName, descriptor)`; успешный ответ уходил в GraphicProvider | Исправлен разбор `[inout]`-ответа; из descriptor сохраняется выбранный LibreOffice `FilterName` |
| Тип `generic_Text` мог давать лишние направления | Один тип реестра используется импортирующими фильтрами Writer и Calc | Сервис берётся из подтверждённого импортного фильтра того же типа; неоднозначный тип без фильтра остаётся неизвестным |
| Linux-проверка CSV завершалась ошибкой API | `ReadOnly=true` передавался LibreOfficeKit как параметры самого CSV-фильтра | Используется собственный параметр LOK `Batch=true`; параметры CSV не подменяются |
| Форматы выглядели автоматически выбранными | Старый `selectedFormats` переживал добавление/замену/очистку файлов | Новый набор очищает выбор форматов. При удалении сохраняются только ещё допустимые пользовательские выборы |
| После удаления файла опять ожидалась проверка | После выполнения и сохранения исчезала prepared-сессия, а сводка не сохранялась отдельно | Для подмножества тех же неизменяемых `File` сводка пересчитывается локально, без HTTP и нового native-импорта |
| Много запланированных сочетаний превращались в пропуски | UI отправлял декартово произведение файлов и общего списка форматов | UI формирует индивидуальный план. Сервер повторно проверяет каждую пару; клиентское утверждение не считается доказательством |
| При сбое проверки «Проблемы» перечисляли десятки неизвестных пар | Корневая ошибка распознавания терялась среди направлений | Одна причина на файл, код и этап проверки; явная кнопка «Повторить проверку направлений» |

Во время проверки подпись на недоступном элементе — «Проверяется…». После проверки неподтверждённый маршрут показывает «Недоступно». «Выбрать всё» не блокируется от того, что все доступные форматы уже выбраны. Самостоятельного выбора форматов при загрузке и распознавании нет.

## Кэш и владение данными

SHA-256 считается при существующей потоковой загрузке блоками по 64 КиБ. Дополнительного чтения целого файла и хранения его байтов в оперативной памяти нет. Ключ включает содержимое, имя, fingerprint реестра и путь/размер/время изменения исполняемого файла LibreOffice. Совпадения имени и размера недостаточно.

Кэш содержит только положительные native-метаданные, не более 256 записей, со сроком `retention_seconds` (по умолчанию 1800 секунд). Ошибки, тайм-ауты и неизвестные результаты не кэшируются. Явная повторная проверка обходит кэш, используя уже загруженную private-копию. При закрытии Guard кэш очищается. Ни процессов, ни потоков, ни таймеров для него не добавлено.

Сводка UI хранит один набор ссылок на неизменяемые `File`. При удалении ссылки на исключённые файлы удаляются из сводки/списка prepared. Серверные копии предварительной сессии остаются во владении задания до изменения prepared-набора, запуска, очистки, истечения сессии или закрытия Guard; они не превращаются в отдельное бессрочное файловое хранилище. После конвертации исходные временные копии удаляются существующим механизмом.

## Ограничения и проверка 00AIO

Windows/NIKITA, настоящий Qt Save, геометрия окна, EXE/Setup и пользовательские документы для этого SHA **NOT_RUN**. Исправление UNO проверено контрактом Python и исходным кодом LibreOffice, но ещё требует запуска на том же Windows LibreOffice, где возникла ошибка. Windows-путь владельца с bundled Python и его обработка расширений реестра сохранены.

Перед интеграцией проверить на Windows:

1. Загрузить исходные CSV и BMP. До ручного клика нет выбранных форматов и активного запуска. Для каждого типа действуют одинаковые правила доступности.
2. Проверить `FilterName` CSV из native-ответа: должен соответствовать импортирующему фильтру Calc того же `generic_Text`, а не объединению всех сервисов этого типа. DOCX должен быть недоступен для обычного CSV, DBF — для BMP; подтверждённый PDF должен остаться доступным.
3. Нажать «Выбрать всё». Кнопка остаётся доступной, экспорт ещё не начинается. После запуска число задач соответствует индивидуальному плану; исключённые до старта сочетания не увеличивают знаменатель конвертации.
4. Сохранить результат, удалить один файл. Повторного импорта оставшихся нет; следующая конвертация использует содержимое и native-proof cache. Если установка/реестр изменились или файл подменён, требуется новая проверка.
5. Воспроизвести отмену проверки и сбой UNO/тайм-аут. Нет автоматического разрешения всех форматов. «Проблемы» показывают причину; явный повтор не загружает те же байты снова. Запоздалый результат отменённой проверки не подменяет текущий список.
6. Запустить регрессии с полными исходными ресурсами, затем нативное сохранение и обычную сборку по процедуре владельца. Этот патч не меняет и не запускает защищённый workflow.

Подтверждение native-модели и зарегистрированного экспорта не доказывает успешность преобразования любого повреждённого/зашифрованного/сложного документа. Это не сканер потерь: `qualityCompared=false`; визуальное качество и вся матрица экспортов не проверены. Код прямого экспорта LibreOffice, Excel, CSS, брендовые ресурсы, packaging и workflows не изменены. Новых движков, runtime-зависимостей, сетевого сервиса и ограничений числа/размера/страниц файлов не добавлено.

Исторический прямой `/jobs` API и native-инструменты диагностики сохранены для совместимости. Обычный UI использует `/prepare` → `/preflight` → `/start` с индивидуальным планом; для prepared-сессий `onlyVerified=false` уже не разрешает неизвестные пары.

## Воспроизведение

```bash
python -m unittest discover -s tests -v
# Дополнительно AIO_DOM_MODULE указывает на установленный linkedom/worker.js.
# Native smoke требует установленного LibreOffice, Node, Pillow и pypdf:
python tools/qa/guard_v07_native_acceptance.py --work <new-empty-path>
# Необязательный расширенный пакет (дольше):
python tools/qa/guard_v07_native_acceptance.py --work <another-new-path> --formats pdf,xlsx,dbf,png
```

У harness есть собственный тайм-аут 300 с; это не ограничение пользовательской конвертации. Старые acceptance-инструменты v0.6 проверяют общий cross-product план; для этого патча используется новый v0.7 harness.
