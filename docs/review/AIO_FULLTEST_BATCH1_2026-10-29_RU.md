## Объём

- M18 / D10: небольшой анализ заголовка/хвоста TGA определяет графическую модель, выбирает подтверждённый установленный импортёр TGA. Writer/Text не может подтвердить такой исходник. Без дополнительного сканирования пикселей и второго импорта LO. Поддержаны TGA2 с корректным footer и точный несжатый TGA1; это не универсальный детектор всех двоичных файлов.
- M19 / D01: исходный текст для presentation→XHTML читается из уже загруженной UNO-модели, в том числе старых PPT. Пустой результат не получает ready. Безопасный отказ — НЕ восстановленный текст и НЕ успешная конвертация.
- M20/M21, частично: Draw/Impress с несколькими страницами экспортируются отдельными нативными графическими файлами с AIO-pages.json. Writer/Calc в этот блок пока не входят; весь D02 не закрыт.
- M22: SLK/SYLK используют существующее разбиение Calc по листам, включая CLI fallback. Вычисленные значения сохраняются вместо межлистовых формул; предупреждение явное.
- M23: для XHTML выбирается настоящий XHTML-фильтр, не HTML-фильтр с совпадающим расширением.
- M27: JPEG→семейство JPEG сохраняет исходные байты после структурной проверки и декодирования; дополнительное сжатие не выполняется. Специальный повтор с явными настройками не подменяется копией.
- M32: Windows LibreOffice 26.8.1.1 / стабильный выпуск 26.8.1. MSI SHA256 взят из manifest Microsoft winget-pkgs, проверяется до административного извлечения. Версия проверяется при подготовке и PyInstaller-упаковке. Установленная у пользователя программа от этого не меняется.
