# B30/B34 — все листы плоского экспорта и границы доказательств

База: QA `e80cdb84b90f2737b492185a3eb22586570c9f8c`, tree
`a95af6da4f94a1e834af172c054049090dc306e8`. PR-кандидат; Windows-приёмка ожидается.

Обычный Calc → CSV/TAB/TSV теперь использует существующий нативный механизм
отдельных листов: UNO importSheet либо CLI → нативный FODS → частные снимки.
Имена исходных листов сохраняются только как метаданные; имена выходных файлов
ограничены, защищены от Windows device names и содержат уникальный индекс.
Каждый лист сопоставлен с индексом (с нуля), именем, SHA-256 и проверенными
свойствами в `AIO-sheets.json`. Состав и байты комплекта проверяются до ready.
Бюджет сравнения значений даёт явное not_checked; отсутствующий или изменённый
файл, недостающие значения либо неоднозначная привязка не становятся ready.

Статусы API дополнены conversionStatus, saveStatus, readbackVerified,
qualityCheckRequested/qualityCompared, checkedFeatures, unknownReasons,
formatLimitations, confirmedLoss. Старые state/saved/resultChecks сохранены.
Readback сохраняется в журнале и восстанавливается; старые журналы не получают
ретроспективного подтверждения чтения сохранённой копии. SHA/readback не означают
сравнение содержимого с исходником. Проверка CSV относится к модели, импортированной
LibreOffice, и не сертифицирует все свойства исходного Excel.

Формулы становятся значениями; стили и диаграммы отсутствуют по свойствам CSV.
Обычный экспорт сохраняет отображаемые значения. Явный рецепт повторного экспорта
с полной точностью остаётся отдельной стратегией с предупреждением о датах/числах.

Новые тесты: безопасные имена/коллизии, четыре листа, строки и ведущие нули,
многострочный текст, потерянный хвост, изменённые ячейки, неполный комплект,
изменённый SHA, бюджет, отмена, независимость сохранения/качества.
Нативный runner готовит отдельную синтетическую книгу: четыре листа × 600 формул,
по 301 строке × 8 колонок; проверяет все CSV/TAB/TSV через UNO и CLI, однолистовую
книгу, реальную очередь, частичное сохранение, restart и SHA/readback всего пакета.

Доступны приложенное ТЗ, PDF/XLSX-аудит и репозиторные v20–v23 отчёты.
Полный исходный ZIP 680 файлов и отдельно перечисленные MASTER_BUG_BAG,
HANDOFF, STRESS2 Markdown-материалы не найдены; их содержимое не реконструировано.
Генерируемая B30-фикстура не выдаётся за исходный XLSX стресс-теста №2.

Windows NIKITA, регрессии B28 48/48 и B29 108/108, общие Qt/DOM/нативные
проверки должны завершиться на точном опубликованном SHA перед приёмкой.
Пользовательский FULLTEST, установленный EXE/DPI, сборка релиза и merge не выполняются.
