# A.I.O — большой патч Guard v16 по MASTER BUG BAG v15

Дата: 24.10.2026. База: QA PR #15, commit `2992c7afa3b6451cd86f53e734821a3c5579302a`, tree `9bdedc54d8659a956d34a24e0a0eace7463b699b`.
Ветка: `patch/aio-master-bugbag-v16-20261024`. Назначение PR — QA-ветка PR #15, не `main`.

Патч исправляет воспроизведённые причины ложных успехов и потерь, добавляет рабочие пути сохранения исходных байтов и независимый readback. Все пункты исходного мешка разобраны в таблице ниже. Не все направления LibreOffice восстановлены: DBF/DIF, EPUB и часть межформатной анимации требуют дальнейшей нативной работы. Закрытие всех GitHub issues или готовность релиза не заявляются.

## Побайтовый эксперимент по +8 байт

Для `6584-html/03_LEVEL_3.html` обычное readable-чтение Drive вернуло 5702 байта, SHA256 `bc084f0e0d9fa4bd963c0fcd12fa1505ad195a172274b1092125cbd6c54a2637` — точное совпадение с AIO manifest. Raw streamed download вернул 5710 байт с другим SHA. Отличие ограничено четырьмя `<link>`: в каждом `http://purl.org` заменён на `https://purl.org` и добавлен пробел перед `/>`, суммарно +8 байт.

Это локализует изменение данного примера во внешнем пути выдачи/скачивания и не подтверждает дефект записи AIO. Вывод не распространяется автоматически на все 322 файла. Новый readback проверяет локальные байты после записи; поведение внешнего Drive пути он изменить не может.

## Проверки

Финальный доступный source-прогон: 453 PASS, 7 SKIP, 0 ошибок; 2 метода с недоступными исходными PNG отдельно NOT_RUN (всего обнаружено 462). Числа и ограничения записаны в `AIO_GUARD_V16_SOURCE_VALIDATION.json`. Реальные native-проверки и SHA образцов — в [AIO_GUARD_V16_NATIVE_EVIDENCE.json](AIO_GUARD_V16_NATIVE_EVIDENCE.json).

- Нативные positive fixtures: 9 PASS после экспорта и повторного прямого открытия LO; 1 NOT_RUN для отсутствующего Writer→SXW exporter.
- Guard: 7/7 допущенных задач PASS; DOCX/TXT сохраняют все 48 маркеров ячеек, PDF — маркер презентации; четыре same-format результата побайтово совпали с исходниками.
- Сохранение: 7 файлов / 307814 байт независимо прочитаны и сверены.
- Реальные negative controls: 6 PASS, включая повреждённые GZIP, противоречивые Office fixtures и потерю текстов таблицы.
- Linux preflight не допустил реальный APNG (`PREFLIGHT_IMPORT_UNDETERMINED`). Прямой identity-helper этого APNG проверен отдельно; это не выдаётся за выполненный Windows/Guard маршрут.
- JS VM проверяет настоящие bridge/event handlers с управляемыми границами транспорта/сохранения; это не визуальная приёмка Qt.
- Windows NIKITA/GUI, EXE/Setup, полный FULLTEST-510, длительное сравнение скорости, внешний upload/download и сохранение реального VBA — NOT_RUN.

Две проверки исходных PNG бренда >1 MiB не могут полностью выполниться в локальном source checkout: GitHub Contents connector вернул для этих неизменённых бинарных файлов пустой `content`. Они не заменялись заглушками и не входят в патч; в удалённом base tree их SHA сохранены. Исключение явно отражено в source evidence; полный discovery с этой недостающей частью не обозначается PASS.

## Воспроизводимая ограниченная native-приёмка

Использовать настоящий `program/soffice.exe` с соседним установленным реестром фильтров, не wrapper. `--output` должен указывать на новую QA-папку; исходный корпус читается без изменений:

```powershell
python tools/qa/guard_v16_bugbag_acceptance.py --executable "D:\LibreOffice\program\soffice.exe" --output "D:\AIO-QA\v16-targeted" --corpus "D:\AIO-QA\fixtures" --seconds 60
```

`--corpus` необязателен для генерации положительных контролей. Этот скрипт не запускает 14417 задач и не устанавливает приложение. На Windows сначала проверить текущий SHA точечными маршрутами, DBF/DIF с новыми кодами interaction, APNG/анимацию, Qt save и light/dark modal; затем один полный FULLTEST по исправленному корпусу. Слияние в `main` остаётся за владельцем после Windows-приёмки.
