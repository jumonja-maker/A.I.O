## Реализация и доказательство

`qa_wheels.py` перед сетью проверяет SHA исходников, версию Python, всю систему version locks и согласованность wheel inventory. В новой фазовой директории pip получает только binary wheels с заранее зафиксированными хешами. Независимый потоковый SHA-256, верхнеуровневый wheel METADATA и точный inventory проверяются до и после установки. Если pip использовал другую копию/URL, пропустил пакет, выбрал другую версию или хеш, квитанция не создаётся. Квитанция повторно проверяется `verify_qa_dependency_lock.py` перед созданием build manifest.

Без квитанции прежний verifier честно сохраняет `wheelHashesVerified=false`. Прежний тест различения version/byte claims сохранён. Спецификация EXE больше не принимает такой manifest за подтверждённую QA-сборку.

SBOM описывает **Python wheel distributions**. Вложенные vendored библиотеки setuptools, Qt/LibreOffice, системные DLL и их лицензии/CVE ещё не развёрнуты. Наличие SBOM и успешные хеши не означают отсутствие уязвимостей. В квитанции и SBOM прямо указан `SCA not run`.

## Проверка

- 30 реальных wheel/profile пар: 15 Windows + 15 Linux, все SHA-256 совпали с metadata официальных релизов PyPI, имена/версии подтверждены ZIP METADATA.
- **13 новых тестов**, включая изменение байта, чужую package metadata при совпадающем разрешённом хеше, лишние/необычные файлы, неполный/дублирующийся pip report, внешнюю/чужую локальную копию, другую версию/хеш, чужой source SHA, изменение SBOM, правильный binary/hash/local-only install и отказ до сети на другом Python.
- **11 существующих lock-тестов сохранены**, всего целевой suite **24 PASS**. Static workflow assertions обновлены для нового installer + receipt; проверка реального согласования pins с обоими профилями добавлена.
- Локальный Python 3.12 не выдан за реальную установку на 3.11. Сквозная установка, source tests, native Windows LO26.8.2.2 и EXE требуются в hosted exact-SHA CI.

## Неудачные промежуточные проверки

Первый cross-platform Linux download указал единственный manylinux_2_34 tag: pip не выбрал Pillow с более ранним совместимым manylinux tag. Повтор с явно перечисленными совместимыми tags дал все 15 пакетов; версии не ослаблялись. Первичная генерация metadata увидела вложенные vendored dist-info внутри setuptools; проверка уточнена до единственной верхнеуровневой wheel METADATA, отдельная регрессия сохраняет этот контракт. Строгая проверка рабочих download-папок обнаружила оставшиеся временные файлы; она **не ослаблена**: только ожидаемые wheel-байты скопированы в чистые каталоги и независимо сверены. В новой CI wheelhouse лишние файлы приводят к отказу, а не игнорируются.
