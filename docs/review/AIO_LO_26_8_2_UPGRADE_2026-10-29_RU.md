## Источник, выпуск и проверка

- Официальное объявление TDF от 29 октября 2026: https://blog.documentfoundation.org/blog/2026/10/29/libreoffice-26-8-2/
- Выпуск: LibreOffice **26.8.2**, точная версия Windows x86-64 **26.8.2.2**.
- Официальный MSI: `https://download.documentfoundation.org/libreoffice/stable/26.8.2/win/x86_64/LibreOffice_26.8.2_Win_x86-64.msi`
- Официальный опубликованный TDF SHA-256: `https://download.documentfoundation.org/libreoffice/stable/26.8.2/win/x86_64/LibreOffice_26.8.2_Win_x86-64.msi.sha256`
- SHA-256: `ff4b911403b67ee9e6249f820f9782c44bb32c94fdaa45b0da53a8e419e5307a`.
- Закреплённый SHA сравнивается с фактически скачанными MSI-байтами **до** административного извлечения. Версия soffice.com сверяется с 26.8.2.2 после извлечения; в PyInstaller также проверяется точная версия bundled engine.
- Обновлены путь временного размещения Windows engine и имя GitHub-hosted QA, чтобы в логах не числилась старая 26.8.1.
- Linux-матрица пока использует системную LibreOffice для независимой регрессии, а Windows — строго закреплённую 26.8.2.2.
- Сначала обязательный Windows native batch + полный Windows/Linux unittest + EXE packaging/frozen worker smoke. Это **не** 5723-заданный FULLTEST, не запуск установленного GUI и не пользовательский установщик.

## Причина обновления

26.8.2 — официальный bugfix-релиз, включающий исправления аварий и совместимости старых DOC/PPT/XLS. Это **не** свидетельствует, что все A.I.O D01–D12 исправлены: необходимо повторно проверить исходный 200-файловый корпус и отдельно измерить время. Нельзя вычитать случаи из 1079 до такого аудита.

## Приёмка

На момент изменения пина статус **PENDING CI**; ссылки, фактические результаты Windows/Linux и точный SHA ветки будут зафиксированы после завершения прогона. Не маркировать update успешным до фактической проверки по логу.
