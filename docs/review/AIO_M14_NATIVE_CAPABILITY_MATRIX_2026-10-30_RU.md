# M14 — нативная матрица спорных форматов (исследование QA)

Дата: 30.10.2026. Основа: QA PR #83, 22c3d95880cea7821bc651fcaa921f4b8e24cbdf. Работает отдельно в Windows GitHub-hosted QA, без личного NIKITA/AIO-UBUNTU.

## Задача

Проверить, какие маршруты ODC, ODM, ORP, OTM и PSD действительно доступны в конкретной установленной версии LibreOffice, не снимая ограничений Guard по одному расширению файла.

## Включено

1. Отдельные минимальные ODF-пакеты с MIME и body для chart (ODC), text-master (ODM), text-master-template (OTM). Они структурно проверяются и подаются в настоящий native preflight, но не считаются историческими подлинниками.
2. Действительный PSD 2×2 RGB с независимым декодированием Pillow и пиксельным контролем. Формат не объявляется поддержанным на основании одной сигнатуры.
3. Реальный FilterFactory registry на Windows, отдельные import/export services, фактическая native-модель и код отказа, решения маршрутов, одно ограниченное выполнение выбранного подтверждённого маршрута, хеш исходника до/после.
4. ORP: только отрицательный контроль на ложном файле; реального Base ReportDefinition нет, положительное тестирование отмечено NOT_TESTED.
5. Отрицательная проверка устаревшего registryFingerprint: никакой маршрут не может стать registered на одном имени или подменённом пруфе.

## Правила интерпретации

Факт успешной работы скрипта означает только исполнение исследования. Итог всегда SURVEY_COMPLETED_WITH_GAPS / m14Closed=false. Native PASS_SYNTHETIC подтверждает лишь выбранный синтетический маршрут, не качество и не совместимость всех сторонних файлов. SAFE_REJECTION фиксируется честно и не выдаётся за успешную конвертацию.

Windows CI запускает исследование в обязательной стадии нативных vector_pages, сохраняет JSON-данные в журнале Actions без Actions artifacts. Не меняются экспортные маршруты, UI, Guard policy и MAIN.

## Остатки

Нужны подлинный Base ORP, реальные исходники пяти форматов из FULLTEST, независимая проверка содержимого/видимого результата и воспроизведение спорных направлений. M14 остаётся ОТКРЫТО до этих проверок; G02 200 исходников / 5723 заданий / 1079 исторических отклонений не пересчитывались. Никаких фиктивных подтверждений, ручного снятия ограничения или релиза.
