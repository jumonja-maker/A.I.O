# M19 — сохранение уже экспортированных XHTML-ссылок

Дата: 30.10.2026. Базовый QA SHA `ba920941d085679be0105a82659a9dcb849fe0e3`, PR #83. Новый небольшой пакет только в QA.

## Первопричина и воспроизведение

`_AioXhtmlVisualScope` учитывал `<link>`, то есть ресурс документа, но не гиперссылки `<a>`/`<area>`. Кроме того, сравнение visual scope выполнялось только для mixed shapes/images. Контрольная модель, созданная на базе существующего `MixedNativeModel`, сохранила весь требуемый текст и изображение, удалила `<a href="https://example.invalid/original">`, а прежняя функция вернула `checked_subset` и атомарно приняла файл.

Это воспроизведение логики продукта на детерминированной модели, **не утверждение о воспроизведении на оригинальном пользовательском PPT или о поведении Windows LibreOffice**.

## Изменение

- Сравниваются теги a/area/link, точные значения атрибутов, число и порядок ссылок. Перестановка атрибутов в одном теге допускается.
- Дублирующиеся атрибуты ссылки неоднозначны: отказ до изменения приватной UNO-модели.
- Проверка начального XHTML и кандидата обязательна и для текстовых слайдов без графики.
- Исчезновение/изменение ссылки даёт `ENGINE_OUTPUT_VALIDATION_INCOMPLETE`; основной файл остаётся прежним, временный кандидат удаляется.
- В квитанции явно указаны `exportedLinkTargetsCompared`, `exportedHyperlinkCount`. Это сравнение **двух экспортов**, не всех исходных ссылок и не функциональности перехода. `qualityCompared=false` сохранён; `source_links_already_lost_by_native_export` прямо указан в `notChecked`.
- Ограничения 32 страницы / 256 фигур / 16 MiB XHTML, перечень разрешённых нативных объектов, проверка текста и изображений сохранены. Исходный PPT не записывается.

## Что остаётся

M19 остаётся ЧАСТИЧНО. Патч не доказывает сохранение ссылок, уже потерянных первым экспортом LibreOffice, источник/пиксели всех изображений, порядок объектов/слайдов, оформление, анимации или полную визуальную эквивалентность. Для закрытия нужны оригинальные PPT, исходный FULLTEST и независимая проверка каждого результата. Исходные файлы не публикуются в репозиторий.

MAIN/Release, пользовательский установщик и защита ветки не меняются. Google Drive не подключён: обязательное обновление архива 00AIO пока BLOCKED, не выполнено.
