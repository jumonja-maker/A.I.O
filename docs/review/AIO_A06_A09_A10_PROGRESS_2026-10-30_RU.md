### A06 — legacy, только текущий процесс

Авторизованный GET `/api/converter/recover` без `request` возвращает ограниченный список готовых, ещё не освобождённых результатов. Это позволяет найти сгенерированный сервером request ID, когда клиент не сохранил ID и потерял сведения из ответа. Пустой или неверный явно переданный `request` остаётся ошибкой, а не разрешением показать все результаты.

Параметры страницы: `offset` и `limit` (по умолчанию 20, максимум 50). В ответе только имя, размер, MIME, форматы, request ID и адрес существующего recover-by-ID. Нет абсолютных путей, токенов скачивания или огромного отчёта всех целей. Далее клиент явно выбирает ID и получает прежний ticket/downloadUrl. Чтение списка не удаляет результаты и не обходит временные каталоги. Пагинация отражает текущий снимок: при параллельном изменении списка клиент должен обновить его, это не долговременный cursor.

Токен текущей сессии и прежние Host/Origin-проверки обязательны; ответ `Cache-Control: no-store`. Готовый файл остаётся доступен по прежнему механизму аренды на время скачивания.

Введён предел **32 одновременно принадлежащих старому транспорту временных каталогов**. Это не лимит файлов в конвертации и не ограничение очереди Guard. Считаются уникальные временные владельцы среди активных запросов, результатов, скачиваемых/освобождаемых результатов и неудавшейся очистки. Опубликованное, но ещё не завершённое задание считается один раз. При исчерпании лимита новое задание получает HTTP 429 / `LEGACY_STORAGE_LIMIT` до чтения тела загрузки. Существующие несохранённые результаты не вытесняются и не удаляются по TTL. Соединение с непрочитанным телом закрывается, semaphore движка освобождается в finally.

Очистка неопубликованного временного каталога теперь имеет единственного исполнителя: таймер, новый запрос и shutdown не удаляют один и тот же каталог одновременно. Каталог учитывается до фактического успешного удаления; файловый I/O не перенесён под metadata lock.

**Остаток A06:** restart/crash recovery старого транспорта не реализован. Ответ прямо содержит `scope=current_process`, `restartRecovery=false`, `retention=until_release_or_process_shutdown`. Прежнее освобождение legacy-результатов при закрытии процесса не изменено. Не добавлены UI-список, общий дисковый лимит в байтах и доказательство уборки каталогов после аварийного завершения. Основной Guard Recovery — отдельный механизм. A06 остаётся ЧАСТИЧНО.

### A09 — строгая итоговая проверка

В каждом matrix job отдельный завершающий шаг проверяет outcome и conclusion обязательных стадий. Для Linux нужны dependencies, engine, units; для Windows дополнительно native fidelity, vector/colour/compressed routes и EXE package/frozen smoke. Пропуск, отмена и замаскированная через continue-on-error ошибка не считаются успехом.

Новый job **AIO QA gate** зависит от `qa`, запускается с `always()` и принимает только `needs.qa.result == success`. Для будущей очереди слияния добавлен `merge_group: checks_requested`. Фильтров путей нет: изменения launcher/spec/dependencies не исключаются из workflow.

**Остаток A09:** branch protection/ruleset/required-check selection не включались. Само имя check не делает его обязательным в настройках GitHub. MAIN и merge queue не настраивались. После разрешённой интеграции необходимо выбрать канонический SHA, сделать gate обязательным и испытать реальный push main/merge queue. A09 — ЧАСТИЧНО, не закрыто.

### A10 — проверка всего графа lock-файлов

Старый parser пропускал строки `-r`, а сборочный словарь мог перезаписать runtime pin. Новый parser рекурсивно читает локальные включения, разрешает повторное включение уже разобранного файла и отвергает циклы, отсутствующие файлы, выход из проверенной директории, удалённые URL, опции pip и неподдерживаемые условия. Имена нормализуются по группам дефисов/точек/подчёркиваний; разные версии одной зависимости в разных файлах дают ошибку вместо молчаливой подмены.

Оба entrypoint проверяются совместно. `--check-locks` выполняется **до pip install** и не выдаёт подтверждение установленного окружения. Обычная проверка версий после установки, Python 3.11 и source-bound manifest сохранены. `resolvedLockSha256` включает SHA-256 точно прочитанных файлов графа; прежние ключи manifest сохранены.

**Остаток A10:** хеш lock-текста не является хешем wheel. `wheelHashesVerified=false` сохранён. Hash-locked wheels, SBOM, SCA/CVE и воспроизводимый релизный профиль не готовы. Версии пакетов и MSI pin этим пакетом не менялись. A10 остаётся ЧАСТИЧНО.
