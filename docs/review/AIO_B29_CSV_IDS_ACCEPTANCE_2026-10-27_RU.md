## Что проверяет исправление

В поддержанной таблице `001` должен остаться именно строковым значением `001`.
Числовая ячейка `1`, даже с отображением через маску `000`, считается изменением.
Потерянные, переставленные, изменённые ID и формула вместо исходной строки
отклоняются через `ENGINE_OUTPUT_CONTENT_LOSS`. Этот барьер работает без включения
дополнительного анализа «До/После».

В нативную загрузку передаётся штатный формат Text только для распознанных
ID-колонок. Не вся книга превращается в текст. В выбранной колонке смешанные
строковые/числовые поля также становятся текстовыми — это осознанная политика
сохранения буквальной записи исходных полей CSV, не угаданная бизнес-схема.

## Честные границы

Подсказка типов ограничена 64 КиБ / 256 записями. После экспорта ID проверяются
отдельным ограниченным проходом. Если поздний ID не попал в подсказку и был
изменён, его нельзя молча пропустить как ready; автоматическое исправление
всех таких редких случаев этот патч не обещает.

Неизвестная кодировка, несопоставимая структура или превышенный бюджет дают
`CSV_TEXT_IDS_NOT_CHECKED`, а не ложное утверждение о сохранности либо повреждении.
Конкретные пределы и API описаны в `AIO_B29_CSV_IDS_2026-10-27_RU.md`.
