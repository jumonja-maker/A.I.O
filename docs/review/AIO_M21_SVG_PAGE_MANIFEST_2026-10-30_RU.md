# M21 — SVG: верификация сохранения всех страниц

Дата: 30.10.2026. Основа QA PR #83 на SHA 734f826f371174bd29f9ebee10f612050bb3a36a. Изменения изолированы в отдельном Draft PR; MAIN без изменений.

## Факт по исходному корпусу

Оригиналы `02_LEVEL_2.odp` и `02_LEVEL_2.fodp` из пользовательского FULLTEST содержат по четыре страницы. На локальной изолированной LibreOffice 25.2.3.2 нативный GraphicExportFilter по очереди создал четыре непустых SVG для `02_LEVEL_2.odp`; у каждого присутствуют собственные маркеры «Слайд 1»...«Слайд 4», имена и SHA файлов отличаются, исходник сохранился. Это проверка конкретного оригинала/движка, не все исторические случаи и не Windows 26.8.2.2.

## Подтверждённый пробел Guard

`aio_verify_preservation` подтверждает число имен с расширением SVG, но не связывает эти файлы с `AIO-pages.json`. Если в манифесте отсутствует страница, дублируется ссылка, смешан порядок, повреждён JSON или выход пустой, итог мог быть помечен `ready` без обязательной сверки списка. Проверка собственно визуальной эквивалентности не добавлялась.

## Исправление

- Только когда запрошен `svg`, общий адаптер после получения выходов проверяет имеющийся `AIO-pages.json`: точный schema-1, строгие ключи JSON, совпадение числа файлов/записей, порядок страниц и имена `__page_000N`, отсутствие ссылок наружу, неотрицательный размер страниц, регулярные файлы без ссылок.
- Отсутствие манифеста при нескольких SVG и нарушение связности — явный `ENGINE_OUTPUT_VALIDATION_INCOMPLETE` до публикации результата. Одностраничный SVG без манифеста и другие форматы не меняют поведение.
- Объём чтения JSON ограничен 1 МБ, 4096 страниц; входной файл не перечитывается; SVG-векторы и пиксели не рендерятся дополнительно; отмена проверяется внутри обхода.
- `resultChecks` отражает `svg_page_manifest`, `checked_subset` и `qualityCompared=false`; не заявляет сохранность оформления, встроенных ресурсов или визуальную идентичность.
- Новые unit-контроли включают четыре страницы, ошибочные ссылки и нумерацию, дубли ключей, отсутствие/нулевой файл, symlink, превышение лимита, отмену и сохранение одностраничного маршрута.
- Отдельный Windows нативный тест LibreOffice 26.8.2.2 экспортирует четыре различные синтетические страницы SVG, сверяет эксклюзивные текстовые маркеры и обе квитанции Guard. Все артефакты только во временном workspace GitHub Actions.
