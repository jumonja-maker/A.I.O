# Завершение общего FULLTEST-патча

Продолжение уже объединённых PR #40 и #41 на QA-базе `24f8e6bce2f91462ac8ffed25b92be7354c2bd16`. Main не изменяется.

Исправления сохраняют runtime TXT, независимые проверки результатов и ускорения очереди из предыдущих патчей.

- Draw/Impress → HTML/HTM/XHTML: все страницы через штатный экспорт SVG; статические страницы с явным предупреждением об ограничениях интерактивности.
- Изображения → HTML: исходные байты GIF/APNG/WebP сохраняют кадры, прозрачность и холст; TIFF включает все страницы.
- WordML → HTML/HTM/XHTML: встроенные изображения и таблицы, колонтитулы в связанном HTML-компаньоне.
- DBF: полная проверка UTF-8 при отсутствующей кодовой странице; явная кодировка не переопределяется, выводится предупреждение о выборе по содержимому. Смешанные типы сохраняются через native Memo и типизированную карту восстановления.
- DIF: все листы, декларация UTF-8 и хеши файлов; оригинальные байты native DIF не переписываются.
- OPC: допустимые объявления Default вместо Override больше не отклоняют корректные XLSX. Отсутствующая обязательная декларация распознаётся по реальной структуре Office-пакета.
- Полный кадровый путь использует существующий Qt: GIF/APNG/WebP/TIFF, PDF → TIFF 300 DPI, TIFF → PDF с проверкой всех страниц.

## Проверки

Локально: **798 тестов PASS, 0 ошибок, 0 пропусков**, включая исходные изображения брендинга, Qt Widgets, DOM и HTTP. Полный журнал: `evidence/final/source-tests.txt`.

Отдельный workflow проверяет точный commit/tree на NIKITA: source/Qt/DOM, настоящий QtWebEngine, native fixtures, все маршруты/кадры/страницы, WordML и полную матрицу 510 исходников. Итоговые результаты этого запуска будут добавлены после его завершения. Данные и QA-зависимости извлекаются из проверенных offline-архивов без установки пакетов.

Ограничения форматов GIF, DBF и статического HTML отражаются в интерфейсе и отчёте; проверка структуры и хешей не объявляет универсальную визуальную эквивалентность. ORP требует реально установленного экспортёра. Отложенное изменение буфера обмена #27 не включается.

## Повторная проверка Windows

Первый запуск NIKITA #40140983317 выявил отказ Qt TIFF-плагина на последующих страницах и ошибки в Windows-части QA. Исправлены: выбор проверенного TIFF-декодера до чтения кадров, закрытие файлов Qt reader при отмене/раннем выходе, переносимость URL в тесте UNO, проверка исходного ZIP-имени до нормализации Windows и штатный цикл/завершение QtRender. Базовые native-контроли и все шесть WordML-маршрутов в первом запуске прошли; обе темы QtWebEngine прошли проверки, но ненулевой выход процесса не принят за общий PASS. Полная матрица была корректно пропущена до исправления ошибок.
