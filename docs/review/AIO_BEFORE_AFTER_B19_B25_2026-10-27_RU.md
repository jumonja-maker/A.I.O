# B19–B22 / B25: полноценный просмотр и доказуемые различия

Этот PR следует за PR с жизненным циклом сессии (#69). Продуктовые изменения: две панели «До/После», общий масштаб «Вписать / 100% / 200% / 400%», колесо, перемещение, синхронная прокрутка и навигация по страницам/кадрам, режим на весь размер окна. Узкий экран складывает панели вертикально. Исходный файл/HTML не передаётся для выполнения браузеру: показываются PNG из изолированного Qt worker либо инертный извлечённый текст.

Просмотр растрового изображения сохраняет исходное разрешение до 12 млн пикселей. Больший декодируемый файл ограниченно уменьшается; интерфейс явно сообщает это и сохраняет исходные координаты масштаба. Выбранный APNG/TIFF/GIF/WebP кадр/страница проверяется отдельно; PDF использует постраничный QtPdf. Память, байты, число страниц и время worker остаются ограниченными. Токен не попадает в URL, каждый запрос связан с job/task/analysis/output, закрытие отменяет запросы и освобождает Blob URL.

Фильтр заменён видимыми кнопками вместо нативного select popup Qt. По умолчанию показаны проблемные результаты; все пары доступны одним действием. Пустой список по фильтру не объявляет отчёт повреждённым. Сохранение выбранного выхода/диагностики наследуется из #69.

HTML-анализатор извлекает текст body, простые таблицы, изображения и границы проверки без выполнения кода/сетевых запросов. Script/style/head не становятся текстом документа. Скрытое/динамическое содержимое и сложные таблицы остаются явно непроверенными. Полностью совпавший извлечённый текст может быть подтверждён; визуальная эквивалентность HTML не заявляется.

Сопровождающий AIO-sheets.json проверяется независимо: набор файлов, SHA/размер, индекс и имя каждого исходного листа, значения таблиц. Ошибка manifest не превращается в PASS. Подтверждённые различия получают имя листа и координаты ячейки. Неинспектированные сопровождающие файлы остаются unknown.

Локально 51 тест анализаторов PASS; синтаксис JS/Python проверен. Проверки реального DOM и PySide6 выполняются на NIKITA с закреплёнными offline dependencies, локально эти зависимости отсутствуют. Запланированы: native Writer→HTML + сравнение, 4K/alpha preview 100/200/400%, синхронные кадры APNG, мышью фильтр light/dark, narrow/full-size, 100% и 150% scale; старые Qt journeys и полный source/DOM/Excel regression. До результата — **pending**, не PASS.

Это source QtWebEngine QA, не пользовательский FULLTEST и не ручная приёмка установленного EXE. Исторический корпус и его метрика 186/510 недоступны: уменьшение неопределённостей на том же корпусе не заявляется. Новый стресс-корпус и интеграционная проверка идут отдельным этапом.
