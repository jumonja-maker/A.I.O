# B19–B22 / B25: полноценный просмотр и доказуемые различия

Этот PR следует за PR с жизненным циклом сессии (#69). Продуктовые изменения: две панели «До/После», общий масштаб «Вписать / 100% / 200% / 400%», колесо, перемещение, синхронная прокрутка и навигация по страницам/кадрам, настоящий fullscreen Qt Window и документа с проверкой loopback-origin. Узкий экран складывает панели вертикально. Исходный файл/HTML не передаётся для выполнения браузеру: показываются PNG из изолированного Qt worker либо инертный извлечённый текст.

Просмотр растрового изображения сохраняет исходное разрешение до 12 млн пикселей. Больший декодируемый файл ограниченно уменьшается; интерфейс явно сообщает это и сохраняет исходные координаты масштаба. Выбранный APNG/TIFF/GIF/WebP кадр/страница проверяется отдельно; PDF использует постраничный QtPdf. Память, байты, число страниц и время worker остаются ограниченными. Токен не попадает в URL, каждый запрос связан с job/task/analysis/output, закрытие отменяет запросы и освобождает Blob URL.

Фильтр заменён видимыми кнопками вместо нативного select popup Qt. По умолчанию показаны проблемные результаты; все пары доступны одним действием. Пустой список по фильтру не объявляет отчёт повреждённым. Сохранение выбранного выхода/диагностики наследуется из #69.

HTML-анализатор извлекает текст body, простые таблицы, изображения и границы проверки без выполнения кода/сетевых запросов. Script/style/head не становятся текстом документа. Скрытое/динамическое содержимое и сложные таблицы остаются явно непроверенными. Полностью совпавший извлечённый текст может быть подтверждён; визуальная эквивалентность HTML не заявляется.

Сопровождающий AIO-sheets.json проверяется независимо: набор файлов, SHA/размер, индекс и имя каждого исходного листа, значения таблиц. Ошибка manifest не превращается в PASS. Подтверждённые различия получают имя листа и координаты ячейки. Неинспектированные сопровождающие файлы остаются unknown.

## Исправленные причины и сохранённые failures

Первый нативный клик обнаружил нестабильный select popup — заменён доступными кнопками. Проверка масштаба ждёт точный результат WebEngine IPC, а не факт отправки клика. Смена/повторное открытие пары сразу снимает старый preview до HTTP detail: устранён race со старым fullscreen и поздним viewer. Layout ограничен по реальной высоте; report/footer не вытесняются за окно.

Все прежние failure JSON сохранены. В run 40579811557 нативные checks прошли, но общий run был failure из-за устаревшего ожидания journey (четыре проверенные строки при новом default problems). Journey теперь явно выбирает «Все результаты», сохраняя проверки количества, старого completion и повторного открытия. В run 40581401851 journey прошёл, но новый APNG unit ошибочно создавал синий исходник через integer fill RGBA8888 и ожидал красный. Источник создаётся явным QColor и проверяется до записи; строгие red/blue проверки результата и bounds сохранены. Run 40605053344 подтвердил raw legacy pixel `[0,0,255,255]`, explicit `[255,0,0,255]` и 1165 PASS + 10 N/A.

В старом continuity JSON run 40581401851 ошибочно записан nativeSourceSHA текущего QA-коммита; правильный native source был `14494e00fdbc1aaed20b8443b0d59e2554ea91df` (run 40579811557). Run 40605053344 исправил метаданные и подтвердил 14 Git objects. Окончательная приёмка 40605908375 заново выполняет все scopes на одном новом SHA, поэтому не зависит от этой ошибочной старой ссылки.

При визуальном просмотре старых PNG обнаружен устаревший compositor frame после fullscreen: одного совпадения широкого одноцветного участка было недостаточно. Добавлены три exact-colour markers. Их первый прогон 40605322789 обнаружил ошибку QA: метки были под `dialog::backdrop`, поэтому затемнялись. Они перенесены внутрь modal top layer, числовые пороги не ослаблены. Последний полный run проверил актуальные кадры успешно. Старые снимки 40571815044/40579811557 не являются принятыми визуальными доказательствами.
