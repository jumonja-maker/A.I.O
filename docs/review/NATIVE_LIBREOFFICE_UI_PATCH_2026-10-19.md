# A.I.O: прямой LibreOffice без политик UI — передача 00AIO

Дата: 19.10.2026. База: feature/libreoffice-direct-and-ui-geometry-20261019 @ 00444c5f57cd367051f53c330006f34e80643a72.
Патч направляется в эту рабочую ветку, без слияния в main.

## Проблема

BMP нельзя было выбрать в системном диалоге. При перетаскивании сервер отклонял его
с INPUT_NOT_SUPPORTED до запуска LibreOffice. В каталоге отсутствовал Draw;
трёхколоночная полоса показывала только «Документы» и «Таблицы».
Поиск скрывался при одном исходном файле. JS, HTTP и прямой адаптер независимо
устанавливали лимиты 100 файлов, 20/50/100 МиБ, 12 выходных форматов и 90 секунд.
Смешанный набор целиком выключал направления отдельных подходящих файлов.

## Итоговое поведение

- Диалог выбора принимает любые расширения. Байты исходника без предварительного
  разбора ZIP/Office/PDF передаются установленному LibreOffice.
- Метаданные для списка форматов передаются JSON: id, имя, размер. Исходники при
  добавлении, выборе или поиске не загружаются и не конвертируются.
- Каталог собирается из EXPORT-фильтров установленного share/registry/*.xcd.
  На проверенной установке обнаружено 87 расширений. Результат разбора кэшируется.
  COMMON — запасные предложения для неполного каталога, а не allowlist.
- В UI доступны «Документы», «Изображения», «Таблицы» и «Другие».
  Любое синтаксически корректное расширение также принимается прямым API.
- Совместимость обозначена native_decision. Доступная кнопка означает возможность
  отправить запрос движку, а не подтверждённую успешность любой пары форматов.
  Один тип в списке не блокирует другие. Разрешён и экспорт в исходный формат.
- В прямом транспорте и UI нет ограничений размера исходника, набора, результата,
  количества файлов/форматов, страниц или времени конвертации. Политики и дедлайны
  должен задавать будущий Converter Guard.
- Сохраняются проверки структуры HTTP, имён/путей, идентификаторов, токена и origin.
  Буфер 64 КиБ и предел заголовка MIME — параметры протокола, а не размер документа.
- Файлы multipart и результаты читаются/пишутся потоками через диск.
  Конвертер не строит большие Python bytes, браузерные Blob или base64 результатов.
- Каждая пара файл/формат выполняется отдельно. Ошибка импорта/экспорта не уничтожает
  последующие результаты. Пользователь получает успешную часть и конкретный отчёт.
  При частичном результате JSON-отчёт включается в ZIP.
- Дополнительные файлы HTML/изображения сохраняются вместе с HTML, с относительными
  путями. ZIP_STORED/ZIP64 не требует повторного сжатия готовых документов.
- Сохранение идёт по same-origin ticket. Отмена диалога оставляет результат для
  повторной попытки. Сброс или подтверждённое сохранение освобождает владельца.
  Во время скачивания очистка отложена до завершения lease.
- Собственный процесс LibreOffice использует отдельный профиль; отмена завершает
  принадлежащее заданию дерево процессов. Пользовательский открытый LibreOffice
  не завершается глобальным taskkill. Фиксированного тайм-аута в адаптере нет.

## Исправления UI

1. Поиск видим при 0, 1 и 3+ файлах; размер строки и положение первого файла стабильны.
2. Вместо (3/100) показывается фактическое число. Добавленные сверх 100 файлы не теряются.
3. Категории строятся по фактическому каталогу, сетка не оставляет пустую третью ячейку.
4. Фильтр остаётся открытым; анимация прозрачности не меняет его геометрию.
5. Панели рассчитываются от доступного пространства AIO, а не полной высоты экрана.
   Низ окна и кнопки помещаются в рамку; при узком рабочем пространстве панели
   располагаются последовательно с обычной прокруткой.
6. В узкой левой панели действия занимают заранее определённые две строки.
   «Фильтр» и кнопки диагностики не обрезаются в проверенных сценариях.
7. Клик по строке и кружку выбирает файл один раз. Доступны Enter/Пробел.
   Прокрутка списка сохраняется при перерисовке.
8. Выбранные форматы и категория сохраняются при редактировании списка;
   устаревший результат и наблюдатель прогресса освобождаются.
9. Зелёная заливка относится к обработке, после неё видна зелёная галочка.
   После подтверждённого сохранения исчезают и галочка, и заливка.
10. Подробности «Проблемы» включают ошибки всех неудачных направлений, включая
    полностью неудачное задание. Дополнительная диагностика не блокирует запуск.
11. Скроллер диагностического окна использует общие токены темы.
12. Профиль Qt живёт до завершения страницы: устранено предупреждение о его
    преждевременном уничтожении на проверенном Linux Qt WebEngine.

## Качество и реальные границы

Используются штатные параметры LibreOffice. Патч не подменяет изображения/текст,
не меняет структуру документа и не обещает «без потерь». Сжатие PDF, DPI, страницы,
анимация, внешние ресурсы, шрифты, макросы и активное содержимое требуют политик и
проверок Guard. Свежий профиль не является ОС-песочницей.

Графический экспорт Draw по умолчанию создаёт представление страницы: тестовый
BMP 96×64 превратился в PNG/JPEG 794×1123. Это поведение самого LO, не исправляемое
самовольной обрезкой/перекомпоновкой в оболочке. В справке к графическим форматам
есть предупреждение. Экспорт многостраничного документа в один графический файл
не объявлен сохранением всех страниц.

Каталог экспортов не доказывает каждую входную/выходную пару. Ошибку определяет
реальная попытка LibreOffice. Полный пользовательский корпус не прогонялся.
Поле FILENAME сохраняет исходное имя там, где оно допустимо в ОС; временный путь
отличается, а ограничения файловой системы могут требовать алиаса с предупреждением.

Windows Job Object, установленный Windows GUI, EXE/инсталлятор, NIKITA и настоящий
системный диалог Windows — NOT_RUN. Workflow, установщик и зависимости приложения
в этом патче не изменены. GitHub CI фиксируется отдельно в PR, локальный PASS
не обозначает успешный GitHub workflow.

## Передача Guard

Это патч прямого адаптера к 00444c5, не слияние PR #2 с Guard.
У Guard @ ccb8300 отдельный начальный адаптер «10 офисных входов → PDF».
При интеграции выбрать единый native transport/adapter и единый API UI.
Не возвращать старые acceptedExtensions, MAX_FILES, семейные veto, отдельные
20/50/100 МиБ или таймер 90 секунд в UI. Ограничения Guard должны сопровождаться
его собственным кодом/причиной; UI только отображает решение.

Прежний рендерер, Advanced и старые движки не возвращены.
Excel остаётся независимым: его ограничения и проверки относятся к объединению,
а не применяются к конвертеру LibreOffice.

## Воспроизведение

Запуск приложения: python launcher.py.
AIO_LIBREOFFICE — путь к soffice; AIO_LIBREOFFICE_ROOT — совместимый вариант пути
к установке. При нестандартной обёртке AIO_LIBREOFFICE_REGISTRY указывает каталог
share/registry. Обычная Windows установка обнаруживается без этого параметра.

python -m unittest discover -s tests -v
node --check src/converter-bridge.js

Для DOM задать AIO_DOM_MODULE с путём к имеющемуся linkedom.
Для синтетического native QA установить только в QA-окружение python-docx,
python-pptx, Pillow, pypdf, openpyxl и выполнить:
python tools/qa/native_converter_acceptance.py --work /new/empty/directory

Для Qt QA задать AIO_UI_QA_OUTPUT и выполнить:
python tools/qa/native_ui_geometry.py

Открывать main/релиз для пользователей после отдельной Windows приёмки.
