## Испытания и запреты

Новый код JS **проверен только синтаксическим разбором** в текущей инженерной сессии; регрессионные тесты добавлены, но их исполнение и Windows проверка пока **не подтверждены**. PR #21 Windows NIKITA run #39766354303 относится **к исходному v13 до PR #22**. Нельзя использовать его как CI PR #22.

Нельзя заявлять, что ODC гарантированно конвертируется, что ODT→CSV/SVG/EPUB обязаны работать на каждом LO, что readback файлов означает полную fidelity, или что Qt save больше не зависает. Все эти результаты требуют прямых испытаний.

Не запускать полный 255×~7326 FULLTEST, новую сборку, установщик, Windows QA и не проводить merge в main без новой команды владельца.
