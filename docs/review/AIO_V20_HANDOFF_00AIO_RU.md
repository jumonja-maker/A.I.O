DIF gate проверяет импорт чисел в домене IEEE double; полное качество PDF из него не следует. JPEG остаётся lossy, GIF palette ограничения не отключены, APNG требует настоящего encoder.

Для диагностики ошибочных outputs можно явно задать `AIO_GUARD_REJECTED_OUTPUT_BYTES`, от нуля до 8388608. Ноль — обычный режим без копирования образцов. Включённые образцы не являются результатами для сохранения и очищаются вместе с owning job.

Условия дальнейшего выпуска: один новый полный пользовательский FULLTEST с build/LO identity, проверкой всех сохранённых SHA и содержимого; несколько циклов настоящего GUI save→clear→idle с RSS/handles/JS paint; отдельная матрица проблемного DIF locale и визуальная проверка сложных документов. Никакие старые результаты FULLTEST не приписываются автоматически этому SHA. Публичный релиз и merge в main этим PR не выполнялись.
