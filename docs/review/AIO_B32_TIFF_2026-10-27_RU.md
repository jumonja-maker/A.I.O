# B32: чтение каждой страницы TIFF на Windows Qt

База: QA `e80cdb84b90f2737b492185a3eb22586570c9f8c`.

Причина воспроизведена на NIKITA в run 40548760998: Qt TIFF reader после read() страницы 0 возвращает false на jumpToImage(1), хотя отдельный reader успешно читает каждую из 6/7/8 страниц. SHA и подробный probe сохранены в evidence PR B13/B31. Guard правомерно останавливал конвертацию; проверку не отключали.

Исправление: независимый reader для каждого ранее проверенного IFD TIFF. Индексы миниатюр, ориентация, размеры, ограничения памяти, отмена и строгие проверки контейнера сохранены. Анимации GIF/WebP продолжают использовать последовательный reader.

Проверки: локальный воспроизводящий контракт reader и отказ на недоступной странице; план NIKITA — 24 пары (tif/tiff × 6/7/8 страниц × PDF/PNG/WebP/APNG), независимый разбор PNG/APNG, WebP frame containers, PDF XObjects; сравнение всех пикселей каждого кадра с заранее заданным эталоном, SHA исходников и отрицательные усечённые TIFF. До результата native QA статус pending. Исторические пользовательские TIFF не предоставлены, это новый синтетический корпус.
