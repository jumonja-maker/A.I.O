### Windows-процессы и профиль — PR #75

Первоначальный общий прогон 40607773754 не прошёл retained queue → partial save/recovery. Коррекция короткого private profile помогла нативному импорту, но последующий прогон 40615730409 нашёл живой child при нуле Job Object ActiveProcesses. Эти FAIL сохранены без изменения статусов.

Дополнительные исправления 00AIO:

- Windows launcher создаётся приостановленным, помещается в собственный Job Object, затем проверяется и возобновляется принадлежащий ему начальный поток. Только после этого вызывается startup callback. Закрыто окно, в котором bootstrap мог породить потомка до assignment.
- До TerminateJobObject удерживаются дескрипторы наблюдаемых членов собственного Job Object. Завершение подтверждается их сигналами вместе со счётчиком, а не одним ActiveProcesses=0. PID reuse/неверное членство/ошибка API не превращаются в verified stop.
- Короткий профиль с owner token/stat/reparse-проверками сохранён; фабрика получает новый дочерний путь. При неподтверждённой остановке удаление профиля не объявляется безопасным. Оригиналы, сохранённые файлы и чужие процессы не входят в cleanup.
