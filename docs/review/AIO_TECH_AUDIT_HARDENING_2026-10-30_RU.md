Дата: 30.10.2026. Рабочий PR #83, база для исправлений: `afdcf56597dd3f8105dc28f1f11365cf7891a4f0`. Сопоставление выполняется с неизменённой `main` (`2bab2d0`). Изменения предназначены **только для QA**, PR остаётся Draft, MAIN и установщик не изменяются.

## Регрессии и приёмка

Новые тесты используют настоящие файлы, openpyxl и локальные HTTP-соединения; они не выдают синтетический LibreOffice FakeAdapter за нативное преобразование. Проверяются Windows-пути/ADS и кириллица, локальные имена Excel, печатные параметры и колонтитулы, зависшее Excel-тело с последующим успешным объединением, восстановление legacy ticket по ID и отказ при неверном ID, поздняя и ранняя отмена Guard.

Хронология ошибок кандидата не скрывается: в первом общем прогоне тест ожидал пробел в MIME-имени, тогда как стандартный MIME-парсер удалил его ещё при разборе заголовка. Убрано неверное ожидание, проверка опасных имён сохранена.

Нельзя объявлять полностью закрытыми инфраструктурные ограничения A09/A10, вопрос накопления результатов устаревших клиентов без ID (A06) и тест FULLTEST только потому, что CI зелёный. Перед MAIN дополнительно нужны Windows GUI/установщик, полный исторический FULLTEST и независимый анализ внешнего сохранения ZIP.
