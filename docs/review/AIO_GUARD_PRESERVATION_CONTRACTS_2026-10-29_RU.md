# Guard: лёгкие требования к сохранности страниц и листов

Продолжение PR #83. MAIN не изменяется. Новый механизм не включает «До/После», Advanced, BlackBox или новый глубокий анализ.

## Назначение

Guard формирует неизменяемое требование из уже открытой модели LibreOffice. Исполнитель получает ожидаемое число единиц и использует существующий постраничный/полистовый экспорт. Перед успешным ответом число основных выходов и уникальность имён сверяются с требованием. Служебные CPG/JSON не считаются страницами или листами.

Потерянный/дублированный выход даёт ENGINE_OUTPUT_CONTENT_LOSS. Неподтверждённое число страниц не превращается в предположение «одна страница»: ENGINE_OUTPUT_VALIDATION_INCOMPLETE. Ошибка после отправленного UNO-запроса не обходит проверку повторным CLI-вызовом.

## Область первого блока

- Calc → CSV/TAB/TSV/DBF/DIF/SLK/SYLK: все листы импортированной книги.
- Draw/Impress → реализованные PNG/JPEG/BMP/GIF/TIFF/WebP/SVG: все страницы импортированной модели.
- Writer → PNG/JPEG и его расширения/WebP: все страницы текущей нативной вёрстки.
- На других маршрутах универсальный дополнительный анализ не запускается.

Результат попадает в существующий resultChecks как native_preservation_contract. Отчёт содержит expectedUnits, observedOutputs, scope и qualityCompared=false. Это проверка охвата, а не доказательство правильности импорта исходника, пикселей, шрифтов или текста.

## Скорость

Планировщик работает только с метаданными. Нет чтения исходника, создания дополнительного процесса LibreOffice, экспорта пробного файла или прохода по пикселям. Один необходимый счётчик модели передаётся существующему экспортёру вместо повторного запроса. Проверка использует уже сформированный список результатов после существующей проверки файлов. Стоимость всего FULLTEST ещё требуется измерить на сопоставимом запуске.

## Границы

Calc → изображения этим блоком НЕ исправлен: результат явно отмечается not_checked с причиной calc_graphic_page_scope_not_implemented. Обычный CLI без подтверждения открытой модели также получает not_checked; его существующие защиты не удаляются. Новые контракты не отключают действующие проверки текста XHTML, типов CSV, TGA, DBF и медиа.

15 изолированных unit-тестов проверяют политики, отсутствие I/O/процессов, недостоверные счётчики, недостающие/лишние/повторяющиеся имена и честную область проверки. Нативная Windows-приёмка расширяется проверкой семи реальных подтверждений страниц/листов. PASS нативной интеграции и упаковки должен быть подтверждён точным CI-коммитом, не этим планом.

Исторический FULLTEST 200/5723, 1079 отклонений, общий benchmark, пользовательский установщик и оставшиеся пункты мешка не закрыты этим блоком.
