# A.I.O — M01/M13/M15: адаптивность и постоянные места кнопок

Дата: 30.10.2026. База: `975d5717b9a79bdf9e59156aca7587973f7e9881`, PR #83.

## Объём

- M01: устранение конфликтов фиксированных/минимальных высот. Панели имеют минимально пригодную высоту, низкое окно прокручивает рабочую область. Узкая область размещает панели друг под другом, заголовок/фильтр/добавление/очистка не должны наезжать на поиск. Списки прокручиваются внутри своих панелей.
- M13: emoji мусорки заменён монохромным SVG с currentColor. Активная кнопка использует существующий токен danger, недоступная — muted в обеих темах. Обработчик удаления, блокировки и подтверждения сохранены; иконка декоративная, aria-label остаётся на кнопке.
- M15: отдельные постоянные ячейки footer для сводки, статуса, запуска/повтора и сохранения/закрытия. Пока запуск скрыт, его место сохраняется, но кнопка невидима и недоступна для фокуса. Длинный статус прокручивается, а не сдвигает кнопки. Повтор до сохранения не разрешается новым обходом.

Материализация сохраняет исходные SHA-проверки и все прежние этапы UI; новый этап меняет только точную единственную строку SVG. CSS не добавляет JS-таймеров, ResizeObserver/MutationObserver, запросов Guard, сканирования, native-импортов или тяжёлой проверки документов.

## Приёмка

Добавлены четыре целевых source-теста и один запуск настоящего Qt WebEngine с production UI/HTTP и существующим синтетическим native-адаптером. Проверяются две темы × пять сочетаний размеров/браузерного масштаба, состояния пустого списка/готового результата/сохранения/отменённого сохранения/повтора, границы панелей, отсутствие перекрытий, цвет и неактивность мусорки, недоступность скрытого слота фокусу и досягаемость повтора через прокрутку.
