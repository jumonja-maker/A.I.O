# A.I.O — All in One помощник

**A.I.O** — настольное приложение для работы с файлами. В актуальной ветке `main` сохранены оригинальная оболочка с двумя темами, **Объединитель Excel** и **конвертер с прямым подключением LibreOffice**. Приложение имеет собственный интерфейс и использует LibreOffice как отдельный движок преобразования; оно не является версией LibreOffice.

> **Состояние проекта (19.10.2026):** проверенная базовая архитектура интегрирована в `main`. Converter Guard ещё не подключён, Advanced заморожен. Сейчас GPT Work готовит фильтр допустимых направлений конвертации; пользовательские массовые тесты отложены до его интеграции. Исторический [PR #2](https://github.com/jumonja-maker/A.I.O/pull/2) **не** используется как основа нового Guard: его структура устарела.

## A.I.O + Converter Guard v0.5 (патч поверх PR #9)

Эта ветка продолжает [интеграцию Guard в PR #9](https://github.com/jumonja-maker/A.I.O/pull/9). Весь выбор форматов передаётся в Guard: интерфейс больше не исключает пары по расширению, в том числе у неизвестных и переименованных документов. Guard пропускает невозможные направления после определения native-модели реальным LibreOffice и сохраняет причины в отчёте.

Исправлены передача `ticket` готового результата, доступность неизвестных исходников, отмена с сохранением готовой части, восстановление сохранения при ошибке ZIP и прогресс для более 100 файлов. ETag убирает повторную передачу и перерисовку неизменённого статуса. Готовые результаты, ошибки и пропуски считаются отдельно.

**Статус:** Draft для интеграции в #9; `main` остаётся без Guard. **167 локальных тестов PASS** и отдельная native-проверка LibreOffice через HTTP/JS bridge. Windows/NIKITA, настоящий Qt Save, EXE и Setup ещё не проверены. Это **не сканер качества**: `qualityCompared=false`. Контракт, ограничения, проверяемые результаты и порядок передачи 00AIO — [Guard v0.5](docs/CONVERTER_GUARD_V05.md). История: [v0.4](docs/CONVERTER_GUARD_V04.md), [первичная интеграция](docs/GUARD_AIO_INTEGRATION_2026-10-19.md).

## Возможности

### Объединитель Excel

- Независимый от LibreOffice и Guard модуль объединения `.xlsx`.
- Сохранение текстовых значений (включая ведущие нули) и проверка целостности входных XLSX.
- Собственная обработка ошибок; изменения конвертера не должны ломать Excel.

### Конвертер файлов × LibreOffice

- Прямой запуск внешнего LibreOffice без старого конвертерного backend.
- Доступные для попытки экспорта форматы определяются установленными фильтрами LibreOffice, а не старым жёстким списком разрешённых расширений.
- Разные исходные форматы допускаются в одном задании. Потоковая загрузка, временные каталоги на диске, ZIP64, результаты отдельных успешных преобразований и отчёт об ошибках.
- Отмена заданий, повторное сохранение и обработка разорванных соединений, в том числе на Windows.
- Сохранены темы, интерфейс выбора файлов, поиск, отображение проблем и прокрутка узких окон.

**Важно:** отображение формата означает возможность запросить преобразование, а **не гарантию совместимости или сохранения качества**. LibreOffice самостоятельно решает, сможет ли импортировать и экспортировать конкретную пару форматов. Например, графический экспорт через Draw может сохранять страницу, а не исходные пиксельные размеры.

В `main` Guard пока отсутствует: при широком выборе форматов ранее наблюдались **284 выходных файла из 3 исходных**. В этой ветке фильтрация основана на native-модели и реестре установленного LibreOffice. Количество возможных результатов зависит от движка; формат не запрещается только по имени исходника.

## Запуск из исходников

Требуются Python 3.11, зависимости из `requirements.txt` и **отдельно установленный LibreOffice** для работы конвертера.

```bash
python -m pip install -r requirements.txt
python launcher.py
```

При необходимости укажите путь к установленному движку через переменную окружения `AIO_LIBREOFFICE` или `AIO_LIBREOFFICE_ROOT`. Без обнаруженного LibreOffice интерфейс может открыться, но конвертация будет недоступна.

Для запуска существующих автоматических регрессий:

```bash
python -m unittest discover -s tests -p 'test_excel.py' -v
python -m unittest discover -s tests -p 'test_clean_foundation.py' -v
python -m unittest discover -s tests -p 'test_libreoffice_direct.py' -v
python -m unittest discover -s tests -p 'test_converter_native_stream.py' -v
```

## Windows QA-сборка

Сборка использует **PyInstaller** и **Inno Setup**. `AllInOne.spec` требует указать `AIO_LIBREOFFICE_ROOT` с **полным** каталогом LibreOffice: движок вместе с каталогами, библиотеками и файлами лицензий включается в Windows-пакет. Настройка только на `soffice.exe` недостаточна.

Сборка [NIKITA #39303919513](https://github.com/jumonja-maker/A.I.O/actions/runs/39303919513) прошла **46 автоматических тестов** (Excel — 16, оболочка — 5, LibreOffice — 8, транспорт — 17), успешно создала Windows EXE и портативный ZIP. **Доставка артефактов через GitHub не удалась** из-за превышения квоты Actions, поэтому статус workflow `success` не означает наличие скачиваемых файлов. Массовые пользовательские проверки отложены до появления нового фильтра Guard.

Это QA-база, **не публичный релиз**.
