# A.I.O — All in One помощник

## Этап: прямое подключение LibreOffice, без Converter Guard

Исходная оболочка A.I.O и Объединитель Excel сохранены. Вкладка **«Конвертер файлов X LibreOffice»** теперь использует новый самостоятельный транспорт `src/converter-bridge.js` и `app_backend/libreoffice_engine.py`, а не старую систему защиты, роутов и конвертерных обработчиков.

Интерфейс A.I.O передаёт исходные файлы штатному LibreOffice. Объединитель Excel использует независимый XLSX-движок.

**Guard передаст GPT Work отдельно.** В этой ветке отсутствуют его код и механизмы блокировки. Advanced заморожен.

### Прямой LibreOffice без политик UI

Выбор файлов принимает любые расширения. Конкретную возможность импорта и экспорта определяет LibreOffice при запуске; список форматов строится из его экспортных фильтров. Категории включают изображения и дополнительные форматы. Смешанный набор не отключает направления отдельных файлов.

Ограничения размера/количества файлов, результата, страниц и времени в конвертерном UI и прямом адаптере сняты. Политики задаёт будущий Converter Guard. Исходники и результаты передаются через диск потоками; проверка списка использует только метаданные. Ошибка отдельного преобразования сохраняет остальные результаты, включая вспомогательные файлы HTML.

Поиск остаётся видимым при любом числе файлов. Панели, фильтр, выбор, прогресс и подтверждение сохранения исправлены без возврата старых движков.

**Доступный формат означает возможность отправить запрос движку, а не гарантию успешной конвертации без потерь.** Используются штатные настройки LibreOffice; графический экспорт может сохранять представление страницы. Подробнее: [передача 00AIO и результаты проверок](docs/review/NATIVE_LIBREOFFICE_UI_PATCH_2026-10-19.md).

### QA перед MAIN

Оригинальные прозрачные PNG значка и Эльвы восстановлены из старого репозитория
с проверкой SHA-256. В интерфейсе используются PNG 64–512 px с выбором по DPI,
в окне/EXE/ярлыках — отдельный многоразмерный ICO. Ресурсы уже включены в исходники;
при необходимости пересобрать их: python tools/build_brand_icons.py.
Подробности и происхождение: [восстановление бренда](docs/BRAND_RESTORATION_2026-10-19.md).

1. Повторить автоматические тесты Excel и чистого интерфейса.
2. Запустить тесты прямого LibreOffice и реальные Writer/Calc PDF smoke на NIKITA.
3. Проверить Windows EXE с полным встроенным LibreOffice, native Save, повтор и макет обеих тем.
4. Сравнить результаты документов и таблиц; только после этого переносить проверенную версию в `main`.
5. После установки стабильной версии в `main` получить Guard от GPT Work и интегрировать отдельно.

### Запуск в исходниках

```bash
python -m pip install -r requirements.txt
python launcher.py
python -m unittest discover -s tests -p 'test_excel.py' -v
python -m unittest discover -s tests -p 'test_clean_foundation.py' -v
python -m unittest discover -s tests -p 'test_libreoffice_direct.py' -v
```

Для Windows QA-пакета используйте `AIO_LIBREOFFICE_ROOT` с **полным** проверенным дистрибутивом LibreOffice. PyInstaller откажется собирать Windows-пакет без него.

Исходный архив `jumonja-maker/All-in-One-` остаётся нетронутым. Новая ветка LibreOffice пока **не включена в main**, и установленная Windows-сборка этой ветки ещё требует проверки.
